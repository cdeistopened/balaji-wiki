# Ask Balaji — Startup Strategy, Network State & Geopolitical Analysis Coach

An AI coach built from Balaji Srinivasan's book (The Network State), podcast appearances, essays, and interviews. Not a chatbot impersonating Balaji — a structured library of real frameworks, real quotes, and real decision tools extracted from his work. Every recommendation traces back to a specific source.

## Quick Start

Ask any question about startups, network states, geopolitics, technology, or truth:
- "Evaluate my startup idea"
- "Design a network state for my community"
- "Analyze this event through the tripolar framework"
- "Should I build or reform this institution?"
- "What kind of truth is this claim?"
- "Is this narrative being weaponized?"

Or use a specific skill directly:

### Playbook 1: Startup Strategy (5 skills + 1 standalone)
Evaluate and build a technology startup using Balaji's frameworks.

- `/ask-balaji:billion-dollar-function-identifier` — Find the single function that creates the most value
- `/ask-balaji:physical-to-digital-mapper` — Find the native digital version of any industry
- `/ask-balaji:full-stack-startup-evaluator` — Decide full-stack vs. single-layer
- `/ask-balaji:parallel-society-architect` — Decide whether to build new vs. reform existing

- `/ask-balaji:one-commandment-generator` — Define your community's single moral premise

## What's Inside

### 15 Interactive Skills
Startup evaluation, network state design, geopolitical analysis, and epistemological tools that walk you through specific questions step by step. Each one asks about your situation, applies Balaji's specific frameworks with his actual quotes, and delivers a structured output.

### 17 Framework Guides
Detailed written guides on specific concepts — from the idea maze to the ten components of a network state to the five truth types. Each includes specific quotes, historical examples, and source citations. Organized across four domains: Startup Strategy, Network State, Geopolitics & Media, and Epistemology.

### 3 Playbooks + 2 Standalone Skills
The skills sequence into three playbooks that mirror Balaji's three main domains. The Startup Strategy playbook evaluates ideas from opportunity scanning through build decisions. The Network State playbook designs communities from moral premise through diplomatic recognition. The Geopolitical Analysis playbook maps events through the tripolar framework. Two standalone skills handle truth classification and narrative analysis.

## The Key Difference: Balaji's Specific Frameworks

Balaji doesn't deal in generic startup or political advice. This plugin preserves his precision:

| Generic AI Response | Ask Balaji Response |
|--------------------|---------------------|
| "Evaluate your startup idea" | "Navigate the idea maze. Who else has tried this? Why did they fail? What technology shift makes this newly possible? Map the dead companies, live competitors, and the specific path through the maze." |
| "Build a community" | "Start with the one commandment — a single moral innovation strong enough to attract 1,000 founding members. Then stage: startup society -> network union -> network archipelago -> network state. Zuzalu proved the popup model works." |
| "Analyze geopolitics" | "Three poles: NYT (Woke Capital), CCP (Communist Capital), BTC (Crypto Capital). Every event, technology, and institution maps onto this framework. Ask: which pole benefits? Which pole loses?" |
| "Is this claim true?" | "Which kind of truth? Scientific (replicable), technical (functional), political (consensus), economic (market), cryptographic (mathematical). Each has a different verification method." |
